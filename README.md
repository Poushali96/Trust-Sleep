# Trust-Sleep

Reproducibility package for **“Trust-Sleep: A Trust-Aware Clinical Decision Framework with Selective Prediction for Sleep Apnea Screening.”**

Trust-Sleep combines a raw physiological temporal-CNN branch with an event-centric physiological representation and downstream trust measures (CDT, CERA, CAS), conformal prediction, and selective prediction. The revised evaluation uses a frozen **recording-disjoint** protocol so that no PSG recording contributes epochs to more than one train/validation/calibration/test partition.

## Important data note

The clinical pediatric PSG master dataset (`experiment1b.h5`) is **not included**. Put an authorized copy under `data/experiment1b.h5` or pass its path explicitly. See `DATA_AVAILABILITY.md` for the required HDF5 schema.

Row-level prediction files, pseudonymous recording/source keys, split-index arrays, and train-derived preprocessing arrays are also intentionally excluded from this Git-ready package. They are regenerated by the pipeline for authorized users.

## Quick start — command line

```bash
python -m venv .venv
source .venv/bin/activate              # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python src/run_experiments.py \
  --data /path/to/experiment1b.h5 \
  --output results/runs
```

A timestamped run directory is created under `results/runs/` containing checkpoints, audit files, tables, figures, and `FINAL_SUMMARY.json`.

## Quick start — Google Colab/Jupyter

Open `notebooks/TrustSleep_reproducible.ipynb`, install the requirements, set the path to `experiment1b.h5`, and run all cells. The original one-cell clean-rerun notebook is retained separately for provenance.

## Reproduction design

The fixed target split fractions are:

| Partition | Fraction | Purpose |
|---|---:|---|
| Train | 60% | Model fitting + train-only preprocessing |
| Validation | 10% | Early stopping |
| Platt | 5% | Probability calibration |
| Threshold | 5% | Operating-threshold selection |
| Conformal | 10% | Conformal calibration |
| Test | 10% | Final untouched evaluation |

The five prespecified seeds are **271828, 314159, 161803, 141421, 173205**. Experiment 1 uses seed 271828 for the complete trust-aware analysis. Experiment 2 runs the Full and Raw-Signal-only configurations across all five seeds using the same frozen recording-level split.

## Full vs Raw-Signal-only

- **Full model:** raw four-channel PSG temporal representation **plus** the event-centric physiological descriptor branch, fused before classification.
- **Raw-Signal-only:** the same raw temporal encoder and downstream training/evaluation protocol, but without the event-centric branch.

This matched comparison is designed to isolate the incremental predictive contribution of the event-centric representation while also testing robustness across random initializations.

## Reference results

The included reference run reports the five-seed ensemble results:

| Metric | Full | Raw-Signal-only |
|---|---:|---:|
| F1 | 0.598 | 0.546 |
| ROC-AUC | 0.934 | 0.910 |
| Average precision | 0.645 | 0.584 |
| Empirical conformal coverage (Full) | 0.908 | — |

See `results/reference/tables/` for the complete aggregate outputs and paired recording-bootstrap confidence intervals.
